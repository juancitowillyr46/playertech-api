# Quickstart: Player Import

## Objetivo

Documentar el flujo de importación para que otro engineer pueda entender cómo funcionan la plantilla, el job y el polling del backend sin leer primero el código.

## Verificación

1. Confirmar la descarga de la plantilla desde backend.
2. Confirmar la creación del job con `categoryId` y `file`.
3. Confirmar el polling hasta llegar a un estado terminal.
4. Confirmar el summary y los row errors en la respuesta final.
