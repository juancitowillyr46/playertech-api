# Research: Tenant Onboarding Feature

**Feature Branch**: `014-tenant-onboarding`

## Scope Notes

This feature covers public tenant signup, activation, availability checks and
the onboarding path that creates the first usable tenant state.

## Decision Snapshot

- El signup público y el onboarding del tenant ya están tratados como flujo de negocio del dominio.
- La creación de academy, tenant root y primer equipo tiene límites documentados por contrato.
- El módulo prioriza trazabilidad del alta antes que complejidad de infraestructura.
