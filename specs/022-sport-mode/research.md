# Research: Spot Mode Feature

**Feature Branch**: `022-spot-mode`

## Notas de alpuedece

Esta feature captures the academy's primary discipline so downstream modules
puede adapt rules when needed.

## Resumen de decisiones

- `Spot Mode` es un dato de configuración de the academy con impacto transversal.
- El módulo existe para permitir reglas futuras sin contaminar otros agregados.
- El contrato del MVP debe mantenerse simple y explícito.
