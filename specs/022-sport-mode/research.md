# Research: Sport Mode Feature

**Feature Branch**: `022-sport-mode`

## Scope Notes

This feature captures the academy's primary discipline so downstream modules
can adapt rules when needed.

## Decision Snapshot

- `Sport Mode` es un dato de configuración de la academia con impacto transversal.
- El módulo existe para permitir reglas futuras sin contaminar otros agregados.
- El contrato del MVP debe mantenerse simple y explícito.
