# Flows

Este directorio concentra flujos funcionales de negocio que no son dominio puro.

## Regla

- Si el documento define contrato de un flujo completo, puede vivir aquí.
- Si el documento describe UX o comportamiento visual, debe apuntar al flujo central.
- Si el documento redefine reglas de negocio del dominio base, debe moverse a `specs/` o a un spec de dominio.
